# ✦ Saathi

> **Always by your side.**

The name **Saathi** comes from the Hindi word for **companion**. In everyday life, a saathi is someone who learns with you, helps you through challenges, and is there whenever you need support.

This project was built around that idea an AI companion that assists with studying, coding, and learning while keeping your data private by running entirely on your local machine.

#  Features

AI Chat Assistant
PDF Question Answering
Code Explanation & Debugging
Real-time Streaming Responses
100% Local using Ollama
Clear Chat History
Clean and Minimal UI

# Tech Stack

Python
Streamlit
Ollama
Gemma 3:1B
Requests
PyPDF

#  Getting Started

# Clone the repository

```bash
git clone https://github.com/moksha013/Saathi.git
```

### Install dependencies

```bash
pip install -r requirements.txt
```

### Pull the AI model

```bash
ollama pull gemma3:1b
```

### Run the application

```bash
streamlit run app.py
```
